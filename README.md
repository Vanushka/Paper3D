# 📐 Paper3D AI

Генератор low-poly моделей для papercraft (бумажных моделей) по фотографиям — без нейросетей.

Модель собирается из простых деталей по шаблону «четвероногое»: тело, голова со скосами,
уши, лапы с подушечками, хвост. Размеры задаются ползунками, а по двум фото (под углом
спереди и под углом сзади) на грани переносятся цвета. Результат — OBJ с минимумом граней,
готовый для развёртки в стороннем приложении (например, Pepakura Designer).

## Возможности

- Параметрический шаблон: каждая деталь — отдельная замкнутая выпуклая деталь из 4–12 граней.
- Копланарные треугольники сливаются в многоугольные грани; вогнутые грани делятся на выпуклые.
- Каркас модели поверх фото и подстройка камеры для каждого фото.
- Перенос цветов с фото на грани (текстура-атлас 4096×4096): учитывается видимость,
  отбрасывается фон, стираются нарисованные на фото линии сгиба, невидимые грани
  берут цвет с симметричной стороны.
- 3D-просмотр с текстурой (three.js) и отключаемыми линиями сгиба.
- Экспорт: OBJ без цветов или zip с OBJ + MTL + PNG.
- Сохранение и загрузка параметров в JSON.

## Требования

- Python 3.10 или новее
- Видеокарта не нужна
- Интернет в браузере: 3D-просмотр загружает three.js с CDN (cdn.jsdelivr.net)

## Установка

```bash
git clone <адрес репозитория> Paper3D
cd Paper3D

# окружение — вне папки репозитория
python3 -m venv ~/.venvs/paper3d
source ~/.venvs/paper3d/bin/activate      # Windows: %USERPROFILE%\.venvs\paper3d\Scripts\activate

pip install -r requirements.txt
```

Окружение можно создать и в другом месте — главное, не внутри папки проекта.

## Запуск

```bash
source ~/.venvs/paper3d/bin/activate
streamlit run app.py
```

Приложение откроется на http://localhost:8501. Другой порт: `streamlit run app.py --server.port 8517`.

После обновления кода (`git pull`) перезапустите сервер (`Ctrl+C`, затем снова
`streamlit run app.py`): Streamlit не всегда перезагружает изменённые модули пакета `paper3d`.

## Как пользоваться

1. **Фото.** Слева загрузите два фото: под углом спереди и под углом сзади.
   По умолчанию открыты демо-фото из `samples/`.
2. **Камеры.** Включите «Каркас поверх фото» и в разделе «Камера» подвиньте ползунки, чтобы
   красный каркас лёг на линии сгиба на фото. Чем точнее совпадение, тем аккуратнее лягут цвета.
3. **Форма.** Справа ползунками подгоните размеры деталей. «↺ Сбросить» возвращает значения
   по умолчанию, «💾 Сохранить» скачивает параметры в JSON, его можно загрузить обратно.
4. **Просмотр.** В центре — 3D-модель: мышью вращать, колесом приближать.
   «🎨 Цвета с фото» включает текстуру, «Линии сгиба» — красные рёбра граней.
5. **Экспорт.**
   - «⬇ OBJ без цветов» — только форма, один файл `.obj`;
   - «🎨 OBJ с цветами (zip)» — `.obj` с UV-координатами, материал `.mtl` и текстура `.png`.
     Распакуйте все три файла в одну папку и открывайте `.obj`.

Высота модели в сантиметрах задаётся в поле «Высота модели» — в этих единицах и сохраняется OBJ.

```bash
source ~/.venvs/paper3d/bin/activate

```

## Структура проекта

```
app.py                  интерфейс Streamlit
paper3d/
  template.py           шаблон «четвероногое»: параметры, сборка деталей, ключевые точки
  primitives.py         параллелепипед со скосами, выпуклая оболочка, срез плоскостью
  export.py             слияние граней в многоугольники, экспорт OBJ / OBJ+MTL+PNG
  camera.py             перспективная камера, z-буфер граней, каркас поверх фото
  fit.py                подгонка камеры и размеров по точкам на фото
  texture.py            перенос цветов с фото в текстуру-атлас
  viewer.py             3D-просмотр на three.js
  silhouette.py         загрузка изображений, маска объекта
samples/                демо-фото и подобранные для них камеры (*.camera.json)
tests/                  тесты pytest
```

## Оси и единицы

Y — вверх, Z — вперёд (кот смотрит в +Z), X — вбок. Низ лап — на Y = 0.
Размеры в шаблоне условные, готовая модель масштабируется под заданную высоту.
